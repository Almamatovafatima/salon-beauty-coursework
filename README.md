\# Информационная система «Салон красоты»



\*\*Тема:\*\* Разработка информационной системы для салона красоты.

\*\*Стек технологий:\*\* C#, Avalonia UI, Entity Framework Core, Microsoft SQL Server (LocalDB).



\## Описание

Программа предназначена для автоматизации учета услуг и оформления заказов. 

Система реализует разграничение прав доступа (Администратор, Мастер, Клиент), 

ведение каталога услуг, управление расписанием (слотами) и контроль свободных мест.



\## Структура проекта

\- `Views/` — экранные формы (XAML)

\- `Models/` — модели данных (сущности БД)

\- `Services/` — бизнес-логика и расчеты

\- `Data/` — контекст базы данных и подключение

\- `Assets/` — графические ресурсы (логотипы, картинки услуг)



\## Запуск

1\. Разверните базу данных `salon\_bea` в MS SQL Server.

2\. В файле `connection.txt` укажите корректную строку подключения к вашему серверу.

3\. Запустите приложение.
